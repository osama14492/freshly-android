# تطبيق FRESHLY للأندرويد

هذه حزمة مشروع Android Studio لتغليف ملفي الكاشير والمنيو الحاليين في تطبيق Android واحد، مع شاشة افتتاحية تحمل شعار FRESHLY.

## ما تم الحفاظ عليه
- ملف الكاشير الأصلي ووظائفه وبياناته المحلية ومفاتيح `localStorage` الحالية.
- ملف المنيو الأصلي وتعديلات الأصناف والأسعار المحفوظة محلياً.
- نفس Firebase project وRealtime Database URL ومسارات `pendingOrders` و`orderTracking`.
- لا توجد خطوة تمسح بيانات Firebase أو تعيد تهيئة قاعدة البيانات.

## التشغيل
- التطبيق يفتح من شاشة FRESHLY، ومنها تختار الكاشير أو المنيو.
- يتم تقديم الملفات من أصل محلي ثابت داخل WebView (`appassets.androidplatform.net`) كي تبقى صفحات التطبيق متاحة عند انقطاع الإنترنت.
- يحفظ جسر التشغيل دون اتصال عمليات Firebase `set/update/remove` محلياً ويعيد إرسالها عند عودة الاتصال، كما يحتفظ بنسخة محلية من بيانات الطلبات التي تمت قراءتها.
- المبيعات والفواتير والإعدادات التي يحفظها الكاشير في `localStorage` تظل على الجهاز.

## تنبيه مهم قبل الاعتماد التشغيلي
هذه نسخة تأسيسية تحتاج اختبار قبول على أجهزة المحل قبل توزيعها: خصوصاً الطباعة، تنزيل/استعادة النسخ الاحتياطية، استقبال طلب من جهاز آخر أثناء انقطاع الإنترنت، وتعارض تعديل نفس السجل من جهازين. الطلب الذي ينشأ على جهاز منفصل وهو غير متصل لا يمكن أن يصل للكاشير إلا بعد عودة الاتصال أو وجود خادم محلي على الشبكة.

جسر Firebase يحافظ على إعدادات Firebase الحالية ولا يستبدل قاعدة البيانات. إذا لم تحمل مكتبات Firebase من الإنترنت، يظل وضع التخزين المحلي متاحاً ويحاول الجسر تحميل المكتبات عند عودة الاتصال.

## بناء APK مجاناً عبر GitHub Actions
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد أو مستودع خاص بك.
2. افتح تبويب **Actions**.
3. اختر **Build FRESHLY APK** ثم **Run workflow**.
4. بعد نجاح البناء افتح نتيجة التشغيل وحمّل ملف **FRESHLY-APK** من Artifacts.
5. فك الضغط على الهاتف وثبّت `app-debug.apk`، مع السماح بالتثبيت من هذا المصدر عند طلب Android.

التطبيق مجاني ولا يحتاج اشتراكاً. يتطلب البناء اتصال إنترنت أثناء عملية البناء لتنزيل Gradle ومكتبات Android.
